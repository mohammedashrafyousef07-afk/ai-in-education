# Artificial Intelligence in Education

My first project: an ICT group website at Universiti Teknologi Malaysia exploring how AI can support teaching and learning.

[View the live website](https://ictproject-aieducation.netlify.app/)

## My role

I led our six-person team, wrote the AI content and helped organise the website. This was a collaborative project; the team members and their roles are credited on the site.

## Features

- An introduction to AI in education, with examples and references
- Project poster and image gallery
- Embedded educational videos
- A four-question interactive quiz with scoring
- Background audio with a play/pause control
- Responsive layout and section navigation

## Built with

HTML, CSS and vanilla JavaScript. No package installation or build step is required.

## Run locally

Download this repository, extract it and open `index.html` in a browser. Keep the `assets` folder alongside `index.html`.

For a local server, run `python -m http.server 8000` from the project folder and open `http://localhost:8000`.

An internet connection is needed for Google Fonts and embedded YouTube videos. Audio playback depends on browser autoplay settings.

## Structure

```text
index.html        Page content, styles and interactive quiz
assets/img/       Images, poster and university logo
assets/audio/     Background audio
```
